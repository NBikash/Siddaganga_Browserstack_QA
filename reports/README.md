# reports/

Cross-platform summaries only (e.g. release sign-off comparing Android and iOS runs).
Per-platform execution reports go to `android/reports/` and `ios/reports/`.
Exception: Saagane by Siddaganga run reports go to `reports/saagane/<run-id>/` (see `config/saagane/android.json`).
Never include credentials, OTPs, access keys or personal data.
